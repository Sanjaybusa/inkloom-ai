- (decision) AD-1 [ADOPTED]: Use a public single-page client state machine in src/app/page.tsx; it binds R1-R5 and prevents auth, API, and persistence divergence.
- (decision) AD-2 [ADOPTED]: Run campaign analysis in the browser from deterministic seed rules for this demo; prevent server/API claims that the public evaluation environment does not require.
- (decision) AD-3: Permit the review status to move only from pending to analyzed to approved in a browser session; prevents the passport from being generated before approval.
- (decision) AD-4 [ADOPTED]: Keep finding, evidence, correction, selected-finding, and approval state derived from one campaign review snapshot; prevents details and passport contents from drifting.
- (constraint) No login, signup, backend service, external database, or multi-user persistence is required for the public hackathon path.

- (assumption) Browser-local state is sufficient for judging and will reset on a page reload unless a later story explicitly adds persistence.
- (question) The public hosting provider and environment URL remain open; any static or serverless Next.js host is acceptable if it serves the no-login production build.
